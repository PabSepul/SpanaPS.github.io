Paso 2 de 3

Una línea, tres partes

En JavaScript usamos console.log() para mostrar algo. Miremos la instrucción pieza por pieza:

console.log("Hola, mundo");
1

console

Es la herramienta que usaremos para mostrar información.

2

.log

Es la acción: le pedimos que escriba un mensaje.

3

("...")

Entre comillas ponemos el texto que queremos ver.

i

Un detalle útil: el punto y coma final cierra la instrucción. JavaScript suele entenderla sin él, pero usarlo ayuda a mantener el código ordenado.
